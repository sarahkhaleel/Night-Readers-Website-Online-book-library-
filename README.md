# 📚 Night Readers

> "Find Any Book Of Your Interest Here"

Night Readers is an online book library web application that lets users browse, search, and explore books across multiple genres: Fiction, Romance, Adventure, and Horror. Built using vanilla PHP, HTML, and CSS using MySQL for the database, a deliberate focus on core web fundamentals.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS (vanilla)
- **Backend:** PHP (vanilla)
- **Database:** MySQL (managed via phpMyAdmin)

## 🎓 Academic Context

Night Readers was developed as my semester project, as part of my Bachelor's degree. The project was built entirely with vanilla PHP, HTML, and CSS, without relying on any frameworks, a deliberate choice to build a strong grasp of core web development concepts.

Key learning outcomes included:
- Designing and structuring a relational database schema (MySQL, managed via phpMyAdmin)
- Writing raw SQL queries for CRUD operations (create, read, update, delete)
- Handling server-side logic and form processing in PHP without a framework
- Managing user authentication in PHP
- Structuring a multi-page web application with reusable components

This project reflects foundational full-stack web development skills, the kind of groundwork that framework-based development (Laravel, React, etc.) builds on.
